### ⭐ Fintech (projeto autoral / freelancer)
- **O que é:** plataforma web de gestão financeira pessoal com foco em lançamentos rápidos, automação e visão clara do orçamento.
- **Stack:** PHP • MySQL • Docker • HTML • CSS • Bootstrap • jQuery
- **Principais features:**
  - **CRUD financeiro completo:** transações (receitas/despesas), usuários, categorias e orçamento mensal por categoria
  - **Dashboards:** gastos por categoria, orçamento vs gasto, receitas/despesas, saldo mensal e histórico por período
  - **Importação e normalização:** importação de transações via WhatsApp e tratamento dos dados
  - **Assistente/Chatbot:** responde perguntas sobre os próprios dados financeiros do usuário
  - **Geolocalização:** heatmap de receitas e despesas por localização (GPS ou CEP via API)
  - **Relatórios:** exportação em **PDF** e **Excel** com filtros definidos pelo usuário
  - **Recursos extras:** login, blog de notícias e integração com **API do Banco Central** (câmbio e variação)
  - **Simulador:** calculadora de investimentos para comparar opções e projeções
- **Status:** em andamento (sem repositório público)
